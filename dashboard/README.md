# Tableau Dashboard

The interactive Tableau dashboard suite is published on Tableau Public:

**[Open Ad Performance Intelligence](https://public.tableau.com/app/profile/isfaque.ansari5273/viz/Ad_Performance_Intelligence/01PerformanceCommandCentre)**

The published workbook contains four dashboards:

1. Performance Command Centre
2. Monetisation Intelligence
3. Acquisition Efficiency
4. Supply & Risk Observatory

The workbook and its data are synthetic portfolio demonstrations. They are not connected to a company, advertiser, production account or live advertising platform.

To download a local workbook copy, open the Tableau Public view and use **Download → Tableau Workbook** if enabled for the published workbook.
